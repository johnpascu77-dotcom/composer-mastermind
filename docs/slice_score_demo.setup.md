# MidiSampler / Bitwig setup for "slice_demo"

Generated by slice_score.py. The score assumes exactly this setup; a different setting changes slice lengths and breaks the plan.

## MidiSampler (zone 1 enabled, every other zone OFF)
- Load `slice_test_source.mid` into zone 1's source slot.
- Mode **Slice**, Slice by **beat**, grid **4 beats**, Slice playback **Slice**.
- Range Start/End **0 % - 100 %**.
- First slice key **24** (shown as C0); the 8 slices use keys 24-31 (C0-G0).
- Sustain mode **Loop Forward**, Playback **Trigger (latch)**.
- Speed **100 %**, Sync to host on, zone speed ratio **1**, Voices **8 or more**.
- Stop-All Key **23** (B-1).

## MPL (1 shooter instance: SHOOT1 = channel 1)
- Binary 16 grid, pattern length 16, Rate Normal, External Control ON, each on its own channel, output into MidiSampler.
- Do NOT leave a pattern looping from an earlier run: set MPL's pattern to Stopped (or start from a fresh project) before playing.

## Mastermind / Bitwig
- Load the score, Content mode **Absolute**. Host tempo about **110 BPM** (4/4), start playback at **bar 1**.
- Everything is heard **2 bars after the bundle's bar numbers** (measured). First sound: Bitwig bar 3.
- Piece length: 41 bundle bars = Bitwig bars 3-43. The final section is silent; stop the transport after it.
